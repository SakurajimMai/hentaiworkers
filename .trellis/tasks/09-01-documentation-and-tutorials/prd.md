# 更新项目文档与使用教程

## Goal

把现有文档整理成一套可按读者和任务进入、能够从当前代码与配置复核的中文文档系统。
普通用户应能完成 Web 与 Android 的常用操作，管理员和运维人员应能识别安全的操作顺序，
开发者应能找到本地开发、架构与 API 的真实边界；教程不得把尚未实现或尚未验证的能力写成
既成事实。

## Requirements

- 保留现有 `README.md` 与 `docs/` 的参考文档职责，不做与产品无关的品牌或运行时代码改造。
- `README.md` 提供面向使用、Android 下载、开发、部署、API 和架构的短入口；完整细节留在
  `docs/`，避免复制多份易漂移的说明。
- `docs/README.md` 按普通用户、Android 用户、管理员、运维和开发者重新组织，并增加按目标
  选择教程的入口。
- 更新 Web 用户指南，准确说明导航、搜索、播放、漫画阅读、账号、收藏和历史；明确收藏与
  历史每页 20 条、两类收藏独立分页、登录历史合并漫画，以及游客和登录状态的差异。
- 更新 Android 使用文档，增加 Android 7.0+、五种 APK/ABI 的选择、唯一公开 Release 来源、
  安装与覆盖升级、网站账号登录、本地/云端边界、播放/阅读、更新提醒和按症状排障。
- Android 文档必须明确：更新是启动后的非阻塞拉取检查与弹窗，不是推送、后台下载或静默
  安装；里番目前只写观看标记，不能承诺像 Web 一样按真实秒数跨设备续播；漫画可保存章节
  与页码，但 Web 当前不会自动消费云端页码定位。
- 更新管理员手册，覆盖实际导航、不可逆操作、SMTP 测试后再启用邮箱验证、Turnstile 两层
  开关、Telegram、广告、漫画栏目/发布密钥、Android 下载链接及受限图片代理边界。
- 更新开发与部署文档，纠正 Compose 的真实 `IMAGE_TAG` / `PULL_POLICY` / 端口默认关系、
  管理员 seed 顺序、迁移 `0018`/`0019`、三种健康检查语义、运行时 DDL 现状、Actions 与
  GitHub Releases 的保留范围，以及 CI 产物不等于自动生产部署。
- 不提供当前无法执行的私有 CA 容器用法；明确官方 Compose 尚未挂载 CA。数据库空库基线的
  外键顺序与 MySQL/MariaDB 兼容性未验证前，不把它包装成可直接复制的全新生产建库教程。
- 更新架构文档为事实架构，链接已交付的独立 HTML 架构图及可编辑 JSON，并记录部分漫画/
  后台路径仍直接访问数据库的现状，不把目标分层描述成全局现状。
- API 文档继续把 OpenAPI 定义为匿名公开 API；补齐其范围内的 live、ready、health、ads、
  Android 更新和目录端点，并在 Markdown 中单独列出 Cookie 会话接口与漫画发布集成接口，
  不暗示私有接口已包含在公开 OpenAPI 中。
- 新增任务型教程索引以及 Web 初次使用、Android 安装与更新、生产发布检查、公开 API 快速
  上手教程。参考手册解释完整行为，教程只引导完成一个明确目标并链接回参考手册。
- 所有文档以中文为主；命令、路径、协议、环境变量和产品内实际按钮名保持源码中的形式。
- 不改应用代码、数据库 SQL、Compose、workflow 或生产环境，不修改或纳入根目录用户自有的
  未跟踪 `design.md`。

## Acceptance Criteria

- [x] README 和文档索引都能让五类读者在一跳内找到正确入口，教程与参考文档双向链接。
- [x] Web 指南与当前路由、分页、空/错状态及登录态行为一致，不再使用“我的片单”“本站托管”
  或 Web 自动恢复云端漫画页码等不准确表述。
- [x] Android 教程包含系统要求、五种 APK 选择、Build 39 及以前的签名断点、安装/更新确认、
  本地数据风险和分层故障排查，不承诺推送、静默安装或真实视频秒数续播。
- [x] 管理、开发和部署文档不再包含会被 seed 拒绝的示例密码、错误的默认镜像、缺失的迁移
  清单、不可达的 CA 文件步骤或把 `/api/ready` 当作 schema 验证的说法。
- [x] 部署教程明确区分本地构建与远端不可变镜像拉取，明确数据库/反代/迁移/seed/回滚由
  操作者负责，并列出当前空库基线和运行时 DDL 限制。
- [x] `docs/architecture.md` 链接生产架构 HTML/JSON，并如实描述当前分层例外和发布责任边界。
- [x] `docs/api/README.md` 与 `docs/api/openapi.yaml` 对匿名公开范围一致；静态 Build JSON 明确
  标为示例，私有会话与发布接口被清楚分区。
- [x] 所有新增或修改的 Markdown 相对链接均存在，OpenAPI 可由仓库现有 YAML 解析器读取，
  文档示例中的路径、命令和环境变量已与仓库证据逐项核对。
- [x] `git diff --check`、文档链接检查、OpenAPI 契约测试、TypeScript 测试、边界检查和适用的
  根项目质量检查完成；预先存在且与文档无关的失败单独说明。
- [x] 正式改动只落在任务 scope 内，根 `design.md` 仍保持未跟踪且未修改。
