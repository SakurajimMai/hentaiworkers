# Web 首次使用教程

本教程带你完成一个最短闭环：找到作品、开始播放或阅读、登录账号、加入收藏，并确认历史记录。
完整行为与限制见 [Web 前台使用指南](../user-guide.md)。

## 完成后你将得到

- 能从首页、目录、搜索和标签找到里番或漫画。
- 能在 Web 播放器中继续观看，并在漫画阅读器中回到本机页码。
- 能登录网站账号，在收藏和历史中确认保存结果。

你只需要一个较新的桌面或移动浏览器，以及站点管理员提供的网址。浏览和播放无需先登录。

## 1. 打开导航

1. 打开站点首页 `/`。
2. 桌面端直接使用顶栏的 **首页、里番、漫画、历史、收藏**。
3. 移动端点右上角菜单按钮，使用抽屉中的同名入口。登录和注册也在这个抽屉中。
4. 需要时点太阳或月亮图标切换主题。

## 2. 找到一部作品

最快的方法是顶栏搜索：

1. 在 **搜索里番和漫画** 中输入标题、作者或关键词并回车。
2. `/search` 会分别预览最多 12 条里番和 12 条漫画。
3. 找到目标后点卡片；结果较多时点 **全部里番结果** 或 **全部漫画结果** 继续翻页。

也可以直接打开目录：

- 在 **里番** 中切换 **最近更新** 或 **热门**；目录每页最多 40 部。
- 在 **漫画** 中切换 **最近更新、日榜、周榜、月榜、总榜**；目录每页最多 30 部。
- 在里番播放页或漫画详情页点标签，只查看同类目录中的对应标签结果。

如果没有结果，点 **返回里番馆** 或 **查看全部漫画** 清除条件。里番标签与漫画标签互不相通。

## 3. 播放一部里番

1. 打开里番卡片，等待 ArtPlayer 出现。
2. 页面会请求自动播放；浏览器没有开始播放时，手动点播放按钮。
3. 播放超过 5 秒后暂停或返回首页。
4. 首页出现 **继续观看** 时，点卡片可回到保存位置。

未登录时，这段进度只保存在当前浏览器。达到 90% 或距离结尾不超过 5 秒后，作品会显示为
**已看完**，不再进入继续观看栏目。

播放器显示网络、格式或媒体源错误时，先测试另一部作品。只有单部失败通常表示该作品的媒体地址
不可用；全部页面都失败时再检查当前网络和站点状态。

## 4. 阅读一部漫画

1. 从 **漫画** 目录打开一部作品。
2. 点 **开始阅读**，进入第一个可用章节。当前 Web 详情页不提供章节选择。
3. 向下滚动阅读，观察工具栏中的 `P当前页 / P总页数`。
4. 可用工具栏返回作品、收藏、切换全屏或主题；滚动较深后可点 **回到顶部**。
5. 离开后重新打开同一章节，页面会回到这个浏览器保存的位置。

登录时，章节与页码也会写入账号历史，但 Web 从历史打开漫画时只进入相应章节，具体页仍使用
当前浏览器保存的位置。

## 5. 创建账号或登录

已有网站账号时：

1. 点 **登录**，输入注册邮箱和密码。
2. 登录完成后，站点会尝试把当前浏览器中的里番观看进度合并到账号。

没有账号时：

1. 点 **注册**，填写邮箱、至少 8 位密码和可选昵称。
2. 按页面要求完成人机验证或邮箱验证。注册关闭或邮箱受白名单限制时，页面会明确提示。
3. 忘记密码时打开 `/forgot-password`，通过邮件中的链接设置新密码。

从收藏等受保护页面跳到登录时，成功后会返回原页面。普通登录默认进入 `/favorites`。

## 6. 收藏作品

1. 在里番播放页或漫画详情页点 **收藏**；实心 **♥** 表示已收藏。
2. 打开顶栏 **收藏** 或账号菜单中的 **我的收藏**。
3. 确认作品出现在 **里番** 或 **漫画** 区域。

两区各自每页 20 条并独立翻页。翻动一类不会重置另一类；在卡片右上角点实心爱心可以取消。
加载失败时点 **重新加载**，不要把失败页面当成收藏已被清空。

## 7. 检查历史

1. 打开顶栏 **历史** 或账号菜单中的 **观看历史**。
2. 登录后，页面按最近活动合并里番观看和漫画阅读记录，每页 20 条。
3. 点里番记录验证按秒续播；点漫画记录验证进入保存的章节。

里番记录可单条清除。**清除全部** 会同时删除账号中的里番和漫画历史，并要求二次确认；当前
没有单独清除某一条漫画历史的按钮。

退出登录后，`/history` 只显示当前浏览器中的里番记录，同样每页 20 条，不显示账号中的漫画
记录。

## 8. 验证结果

完成以下检查即可结束教程：

- 返回首页能看到播放超过 5 秒且未看完的里番出现在 **继续观看**。
- `/favorites` 能看到刚收藏的作品，并能分别翻动里番和漫画分页。
- `/history` 在登录时能看到里番与漫画的统一记录；退出后只看到本机里番记录。
- 重新打开同一漫画章节时，当前浏览器能回到本机保存页。

## 遇到问题

| 现象 | 下一步 |
|---|---|
| 搜索没有匹配 | 缩短关键词，或进入对应目录清除搜索/标签 |
| 收藏或历史加载失败 | 点 **重新加载**，再稍后重试 |
| 页面持续加载 | 刷新并检查站点首页；仍失败时联系管理员 |
| 单部视频失败 | 记录作品名和播放器完整错误，测试其他作品 |
| 漫画图片失败 | 刷新章节，并记录作品、章节和页码 |
| 链接为 404 | 内容可能已下架，返回首页或目录 |
