# 后台完整内容显示与爬虫模板管理设计

## 状态

- 日期：2026-07-19
- 用户已确认：采用自适应多行显示；模板删除采用软删除
- 范围：里番编辑页、爬虫模板列表与编辑页、模板启动与计划任务保护

## 背景

里番编辑页当前用单行输入框展示视频地址和封面 URL，长内容不便核对。页面直接读取并提交数据库值，不负责生成或修复历史媒体路径。本次仅改善完整内容的呈现，不修改 URL、文件名或历史对象。

爬虫模板页面当前只支持新建和启动。配置服务已有更新语义，生产仓储使用 `crawler_profiles` 单行保存当前配置并递增 `version`；任务和计划任务保存配置快照。模板与计划任务存在引用关系，物理删除会破坏历史和外键约束，因此删除必须采用软删除。

## 目标

1. 视频地址、封面 URL、剧照和简介按数据库原值完整换行显示。
2. 管理员可以打开模板编辑页，完整回填并保存模板名称与全部配置字段。
3. 管理员可以软删除模板；删除后不能再手动启动或创建计划任务。
4. 删除模板时停用其关联计划任务，同时保留历史任务、日志和配置快照。
5. 所有行为通过服务端权限校验、自动化测试和浏览器验证。

## 非目标

- 不猜测或修复数据库中已经存在的连续点号。
- 不重命名对象存储文件，不批量更新历史媒体 URL。
- 不恢复早期独立 `crawler_profile_versions` 表，不新增数据库迁移。
- 不删除历史任务、事件、日志、任务条目或配置快照。
- 首期不提供已删除模板的恢复界面。

## 完整内容显示

新增后台通用自适应文本域组件。组件接收标准 `textarea` 属性，在首次渲染和用户输入时按 `scrollHeight` 调整高度，并允许 URL 在任意字符处换行。组件不得设置 `maxLength`、`line-clamp`、`text-overflow` 或任何内容替换逻辑。

里番编辑页调整如下：

- 视频地址：由单行输入框改为自适应文本域，保留 `name="videoUrl"` 和必填校验。
- 封面 URL：由单行输入框改为自适应文本域，保留 `name="cover"`。
- 剧照：沿用逗号分隔数据格式，改用同一自适应文本域。
- 简介：改用同一自适应文本域。
- 所有字段继续以数据库原值作为 `defaultValue`，Server Action 原样提交，不增加清洗或重写。

当数据库原值本身含有 `......` 时，页面必须照实显示；前端不尝试还原不存在的数据。

## 模板表单复用

将模板页面现有的新建表单抽取为共享表单组件，支持两种模式：

- 新建模式：使用当前默认值，提交到现有创建动作。
- 编辑模式：接收模板名称和当前配置作为初始值，提交模板 ID、名称及完整配置。

现有 `ProfileSourceFields` 需要扩展为接收初始配置。来源适配器、Base URL、分类 ID、播放标识、日期范围、并发、跳过策略、媒体开关、存储驱动等字段必须完整回填。切换来源时仍可应用来源预设，但编辑页初次加载不得用预设覆盖已保存值。

新增 `/admin/crawler/profiles/[id]` 编辑页。页面必须先执行管理员校验，再读取仍启用的模板；无效、缺失或已删除模板返回 404。保存成功后返回模板列表并显示成功状态。

## 模板更新

应用服务新增明确的编辑用例，输入为 `profileId`、模板名称和配置：

1. 校验 ID 为正整数、名称非空、配置符合 `CrawlerProfileConfig`。
2. 生产仓储在同一条 `UPDATE` 中更新名称、配置、schema version 和更新时间，并将 `version` 加一。
3. 内存仓储保留既有不可变版本测试语义，同时更新模板名称，避免测试替身掩盖名称更新行为。
4. 已创建任务和计划任务中的 `configSnapshotJson` 不随模板编辑改变。

## 模板软删除

删除操作使用现有确认交互，提示“模板将从可用列表移除，关联定时任务将停用，历史任务不会删除”。

服务端按可重试且失败安全的顺序执行：

1. 校验管理员身份和模板 ID。
2. 在调度仓储事务中将该模板的所有启用计划任务设为禁用。
3. 将 `crawler_profiles.is_enabled` 设为 `0`。
4. 刷新模板、任务和计划任务页面缓存后返回成功状态。

先停用计划再隐藏模板，可避免操作中途失败时出现“模板已隐藏但计划仍在继续执行”的状态。重复删除已禁用模板按成功处理，保证操作幂等。

普通模板列表、手动启动选择器和计划任务新建选择器只返回启用模板。历史读取仍可按 ID 获取已保存快照；所有新启动路径必须额外校验模板启用状态，不能仅依赖页面隐藏。

## 页面交互

模板列表每行提供三个清晰命令：

- 启动：进入任务启动页。
- 编辑：进入该模板的独立编辑页。
- 删除：提交软删除动作并显示确认对话框。

操作区保持紧凑，沿用当前后台字体、边框、颜色和按钮层级。删除使用危险操作颜色，但不改变列表整体布局。移动端允许操作区换行，模板名称和来源信息不得被操作按钮遮挡。

## 错误处理

- 配置或名称无效：留在编辑上下文并返回统一失败状态。
- 模板不存在或已删除：编辑页返回 404；新任务启动返回 `RESULT_INVALID`。
- 计划任务停用失败：不隐藏模板，记录原始错误并返回失败状态。
- 模板禁用失败：计划任务已安全停用；重复提交可继续完成禁用。
- 权限失效：沿用现有管理员登录重定向。

## 测试策略

严格执行测试先行：

1. 组件测试先证明长数据库值完整进入 `textarea`，且不存在截断属性或省略转换。
2. 表单测试先证明编辑初始配置能完整回填，并可原样生成配置 JSON。
3. 配置服务测试先证明编辑更新名称、递增版本并保留任务快照语义。
4. 删除服务测试先证明关联计划先停用、模板后禁用、重复删除幂等。
5. 管理动作测试覆盖权限、无效 ID、成功重定向和错误状态。
6. 运行相关 TypeScript 测试、类型检查、ESLint 和生产构建。
7. 启动本地服务，用浏览器分别验证桌面和移动视口：长内容完整换行、编辑回填正确、删除确认无重叠且操作区不溢出。

## 验收标准

- 数据库中存在的完整字段值可在编辑页完整阅读和编辑，不出现 UI 生成的省略号。
- 保存里番后字段值与提交前一致，除管理员主动编辑外无自动变换。
- 模板可编辑且所有配置字段正确回填，保存后版本号递增。
- 删除模板后，其模板和关联计划不再可用于新任务，但历史任务详情仍可访问。
- 删除操作有明确确认，桌面与移动布局均无文本遮挡或按钮溢出。
