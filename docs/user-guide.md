# 前台使用指南

浏览与播放**无需登录**。注册后可跨设备同步收藏。

## 1. 页面说明

| 页面 | 路径 | 功能 |
|------|------|------|
| 首页 | `/` | 精选轮播、热门、最新 |
| 片库 | `/browse` | 全部作品网格、排序、搜索结果 |
| 播放 | `/watch/{id}` | 视频播放、简介、剧照、标签、相关推荐、收藏 |
| 登录 | `/login` | 邮箱 + 密码登录 |
| 注册 | `/register` | 邮箱注册（自动登录） |
| 我的收藏 | `/favorites` | 已登录用户的云端收藏列表 |

## 2. 账号：注册与登录

### 注册

1. 点顶栏 **注册**，或打开 `/register`。
2. 填写**邮箱**（作为登录名，最长 64 字符）、密码（≥ 8 位）、可选昵称。
3. 若管理员开启 **Turnstile**，完成人机验证。
4. 若开启 **邮箱验证**，提交后查收邮件，打开链接完成激活再登录；否则自动登录。
5. 邮箱可能受**白名单**限制；未开放注册时页面会提示。
6. 同一邮箱不可重复注册。

### 登录

1. 顶栏 **登录** → `/login`。
2. 输入注册邮箱与密码。
3. 普通用户进入收藏或 `?next=` 指定页；**管理员**账号会进入 `/admin`。

### 退出

顶栏 **退出**，或在收藏页点「退出登录」。会话 Cookie 清除后需重新登录才能操作收藏。

### 与后台账号的关系

| 角色 | 前台 | 管理后台 `/admin` |
|------|------|-------------------|
| 访客 | 可浏览播放 | 否 |
| 注册用户 `role=user` | 登录 + 收藏 | 否 |
| 管理员 `role=admin` | 可用前台登录入口（会进后台） | 是（`/admin/login`） |

管理员由运维 `seed:admin` 或后台「用户管理」创建，**不能**通过前台注册自提升为管理员。

## 3. 收藏

1. 登录后，在播放页标题旁点 **♡ 收藏** / **♥ 已收藏** 切换。
2. 顶栏 **收藏** 或 `/favorites` 查看列表。
3. 列表中可「取消收藏」。
4. 未登录点收藏会跳转到登录页，登录成功后请返回作品页再点一次。

数据保存在服务端表 `user_favorites`（需已执行迁移 `0003`）。

## 4. 常见浏览操作

### 搜索

1. 顶部搜索框输入片名或关键词。
2. 回车进入 `/browse?search=...`。

### 排序

片库页：**最新** / **热门**。

### 标签筛选

播放页侧栏点标签 → `/browse?tag={id}&tagName=...`。

### 播放

使用浏览器原生视频控件。无法播放多为外链源或网络问题，与账号无关。

## 5. 设备与浏览器

- 桌面与移动浏览器响应式布局。
- 建议较新的 Chrome / Edge / Safari / Firefox。
- 移动端 App（`mobile/`）为独立客户端；云端收藏目前以前台 Web 为准。

## 6. 常见问题

| 问题 | 说明 |
|------|------|
| 注册提示邮箱无效 | 检查格式；邮箱最长 64 字符（与库字段一致） |
| 该邮箱已注册 | 直接登录，或换邮箱 |
| 收藏无效 | 确认已登录且库已跑 `0003-user-favorites` 迁移 |
| 登录后 Cookie 丢失 | 生产环境需 HTTPS |
| 首页无法加载 | 服务端连库失败，稍后重试 |
| 封面裂图 | 外链图床防盗链 / 失效 |

## 7. 管理入口

页脚「管理」进入 `/admin`。**仅管理员**可使用；访客请用前台注册，不要在此后台注册。
