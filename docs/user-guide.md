# 前台使用指南

面向访客的浏览与播放说明。前台**无需登录**。

## 1. 页面说明

| 页面 | 路径 | 功能 |
|------|------|------|
| 首页 | `/` | 精选轮播、热门、最新 |
| 片库 | `/browse` | 全部作品网格、排序、搜索结果 |
| 播放 | `/watch/{id}` | 视频播放、简介、剧照、标签、相关推荐 |

## 2. 常见操作

### 搜索

1. 顶部搜索框输入片名或关键词（支持中文 / 日文标题模糊匹配）。
2. 回车后进入 `/browse?search=...`。
3. 在片库中可继续换页浏览结果。

### 排序

在片库页切换：

- **最新**：按入库/创建时间
- **热门**：按播放量

### 标签筛选

在播放页侧栏点击标签，进入该标签下的作品列表（`/browse?tag={id}&tagName=...`）。

### 播放

1. 点击任意海报或「播放」。
2. 进入播放页后使用浏览器原生视频控件。
3. 若视频无法播放，多为外链源失效或网络限制，与账号无关。

### 相关推荐

播放页下方「相关推荐」优先同系列标题，其次共同标签。

## 3. 设备与浏览器

- 桌面与移动浏览器均可访问响应式布局。
- 建议使用较新的 Chrome / Edge / Safari / Firefox。
- 移动端 App（`mobile/`）为独立客户端，数据同样来自站点 API。

## 4. 常见问题

| 问题 | 说明 |
|------|------|
| 首页提示无法加载 | 多为服务端连库失败或网络问题，稍后重试 |
| 列表为空 | 可能暂无上架作品，或搜索无匹配 |
| 封面裂图 | 外链图床防盗链 / 失效 |
| 无声音或黑屏 | 检查视频源与浏览器权限 |

## 5. 管理入口

页脚可能含「管理」链接，进入 `/admin`。**仅管理员账号**可登录；访客无法在此后台注册。
