# 前台使用指南

浏览与播放**无需登录**。注册后可跨设备同步**片单**与**观看进度**。

本站内容分为两套片库，互不混搜、分表存储：

| 片库 | 入口 | 数据 | 媒体 |
|------|------|------|------|
| **里番** | `/browse`、`/watch/{id}` | `animes` + `tags` | 本站托管 **MP4**（ArtPlayer） |
| **动漫** | `/works`、`/works/{id}` | `anime_works` + `work_tags` | **外链** m3u8/直链（优先线路解析播放器） |

---

## 1. 页面说明

| 页面 | 路径 | 功能 |
|------|------|------|
| 首页 | `/` | 继续观看、动漫精选、里番热门/最新（两套片库分开展示） |
| 里番馆 | `/browse` | 里番网格、排序、搜索 |
| 动漫馆 | `/works` | 日韩/外链动漫列表与搜索 |
| 里番播放 | `/watch/{id}` | ArtPlayer 播 MP4、进度续看、简介/剧照/标签/相关推荐、收藏与片单 |
| 动漫播放 | `/works/{id}` | 线路/分集切换；解析播放器或 ArtPlayer 回退；详情（主演/导演/别名/地区/语言/更新时间/简介） |
| 历史 | `/history` | 观看历史；登录云端同步，未登录存本机 |
| 片单 | `/favorites` | 收藏 / 想看 / 在看 / 已看完 + 自定义列表 |
| 登录 | `/login` | 邮箱 + 密码 |
| 注册 | `/register` | 邮箱注册（可能受白名单 / 人机验证 / 邮箱验证限制） |
| 忘记密码 | `/forgot-password` | 邮件重置（需管理员配置 SMTP） |
| 重置密码 | `/reset-password` | 打开邮件链接设置新密码 |

## 2. 账号：注册、登录与重置密码

### 注册

1. 顶栏 **注册**，或打开 `/register`。
2. 填写**邮箱**（登录名，最长 64 字符）、密码（≥ 8 位）、可选昵称。
3. 若管理员开启 **Turnstile**，完成人机验证。
4. 若开启 **邮箱验证**，查收邮件激活后再登录；否则自动登录。
5. 邮箱可能受**白名单**限制；未开放注册时页面会提示。

### 登录

1. 顶栏 **登录** → `/login`。
2. 输入注册邮箱与密码。
3. 普通用户进入 `?next=` 或默认页；**管理员**进入 `/admin`。
4. 登录成功后，本机观看进度会**自动合并**到云端（若有）。

### 忘记密码

1. 登录页点 **忘记密码？**
2. 输入注册邮箱。无论邮箱是否存在，页面都显示“若已注册则已发送”，避免账号枚举。
3. 站点须已配置 SMTP；否则邮件无法发出。
4. 打开邮件链接（约 60 分钟有效）设置新密码。改密后旧会话会失效，需重新登录。

### 退出

顶栏 **退出**。清除会话后需重新登录才能同步片单与云端进度。

## 3. 播放体验

### 3.1 里番（`/watch/{id}`）

- 使用 **ArtPlayer** 播放本站托管的 progressive **MP4**。
- **记忆续看**：登录用户以云端进度为准；游客用本机记录。起播时若有进度会提示并可跳转。
- **镜像翻转 / 画面旋转**：设置面板可水平/垂直翻转，以及 0° / 90° / 180° / 270° 旋转。
- **移动端横屏**：全屏时尽量锁定横屏（部分浏览器需用户手势，可能被系统拒绝）。
- **右键菜单**：是否允许由管理员配置（关闭时浏览器右键也会被拦截）。
- **广告**（若管理员启用）：
  - **片头广告**：视频优先，其次自定义 HTML，再次图片；可有倒计时与“可关闭”时间。
  - **暂停广告**：暂停正片后覆盖视频/HTML/图片；关闭后可继续播放。片头广告播放期间不会弹暂停广告；拖动进度条时一般不会误弹。

### 3.2 动漫（`/works/{id}`）

1. 选择 **线路** 与 **分集**。
2. 若线路名称/标识匹配后台「线路解析」规则（如红牛 `hnm3u8`），使用第三方 **解析播放器** iframe（地址由管理员配置）。
3. 未匹配且管理员允许回退时，使用 **ArtPlayer + 同源代理**（`/api/media/proxy`）拉取 m3u8，用于源站证书过期、CORS 等问题。
4. 解析播放器路径**不走**本站 ArtPlayer 广告；仅 ArtPlayer 回退时才可能展示广告。
5. 部分 CDN 证书失效时，浏览器直连会失败，代理/解析路径可缓解。

### 3.3 设备与浏览器

- 桌面与移动浏览器响应式布局。
- 建议较新的 Chrome / Edge / Safari / Firefox。
- 独立 `mobile/` 客户端为另一套 UI，**云端片单与进度以前台 Web 为准**。

## 4. 观看进度与继续观看

1. 播放时自动记录进度（起播、约每 20 秒、暂停/离开/结束）。
2. 进度 ≥ 90%（或剩余 ≤ 5 秒）记为**已看完**。
3. 首页 **继续观看**：未看完且进度超过约 5 秒的作品。
4. `/history` 可查看全部历史、清除单条或全部（清除全部会二次确认）。
5. **未登录**：进度存在浏览器 localStorage；**登录后**自动合并到账号。
6. 换设备登录同一账号可从云端进度续看。

---

## 5. 片单（原「收藏」）

1. 播放页 **♡ / ♥** 切换系统「收藏」（跨设备）。
2. 需要时可 **加入：想看 / 在看 / 已看完 / 自定义列表**。
3. `/favorites`（顶栏 **片单**）用 Tab 切换各列表；可新建/删除自定义列表、写备注、移除条目。
4. 未登录点收藏会跳转登录。

> 收藏数据以系统片单 `user_lists` / `user_list_items` 为准。旧表 `user_favorites` 仅作历史回填来源，不再写入。

---

## 6. 搜索

1. 顶栏搜索：片名 / 日文 / 英文 / 简介关键词。
2. 回车进入**当前馆**搜索：
   - 里番页 → `/browse?search=...`
   - 动漫页 → `/works?search=...`
   - 两馆互不混搜。
3. 本机保存**最近搜索**，可点击重搜或清除。
4. 里番馆排序：**最近更新** / **热门**。

## 7. 常见问题

| 问题 | 说明 |
|------|------|
| 没有「继续观看」 | 未播放超过约 5 秒，或已标记看完 |
| 登录后历史为空 | 等待合并完成并刷新；或本机本来没有进度 |
| 忘记密码无邮件 | 管理员未配 SMTP，或邮箱未注册（界面仍提示成功） |
| 里番无法播放 | 源地址失效、存储未公开访问，或网络拦截；与账号无关 |
| 动漫黑屏 / 证书错误 | 外链 CDN 证书过期或防盗链；尝试切换线路，或依赖解析播放器 / 代理回退 |
| 一直在播广告 | 管理员启用了片头广告；等待倒计时或到时可关闭 |
| 暂停总是弹广告 | 管理员启用了暂停广告；点「关闭」继续正片 |
| 移动端无法自动横屏 | 浏览器策略限制，需用户手势进入全屏后才可能锁定 |
| 搜索结果不全 | 确认在对应馆（里番 / 动漫）内搜索 |
