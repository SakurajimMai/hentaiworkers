# 前台使用指南

浏览与播放**无需登录**。注册后可跨设备同步**片单**与**观看进度**。

本站提供**里番**和**漫画**两套目录，标签互不相通：

| 片库 | 入口 | 数据 | 媒体 |
|------|------|------|------|
| **里番** | `/browse`、`/watch/{id}` | `animes` + `tags` | 本站托管 **MP4**（ArtPlayer） |
| **漫画** | `/manga`、`/manga/{id}` | `mangas` 自带标签 | 章节图片滚动阅读 |

---

## 1. 页面说明

| 页面 | 路径 | 功能 |
|------|------|------|
| 首页 | `/` | 幻灯片（管理员可自定义）、继续观看、热门/最新、漫画更新 |
| 浏览 | `/browse` | 里番网格、最近更新 / 热门 |
| 漫画 | `/manga` | 漫画目录、日/周/月/总榜、在线阅读 |
| 搜索 | `/search` | 同时搜里番和漫画 |
| 播放 | `/watch/{id}` | ArtPlayer 播 MP4、进度续看、简介/剧照/标签/相关推荐、收藏 |
| 阅读 | `/manga/{id}/read/{n}` | 纵向连续滚图；阅读页不进索引 |
| 历史 | `/history` | 观看历史；登录云端同步，未登录存本机 |
| 收藏 | `/favorites` | 已收藏的里番和漫画；卡片右上角实心 ♥ 可取消 |
| 用户中心 | `/account` | 显示名、修改密码、收藏统计；管理员可见「管理中心」入口 |
| 登录 | `/login` | 邮箱 + 密码 |
| 注册 | `/register` | 邮箱注册（可能受白名单 / 人机验证 / 邮箱验证限制） |
| 忘记密码 | `/forgot-password` | 邮件重置 |
| 重置密码 | `/reset-password` | 打开邮件链接设置新密码 |

顶栏右侧提供**日/夜主题切换**；登录后顶栏显示**用户菜单**（用户中心 / 我的片单 / 观看历史 / 退出，管理员额外有管理中心）。

## 2. 账号：注册、登录与重置密码

### 注册

1. 顶栏 **注册**，或打开 `/register`。
2. 填写**邮箱**（登录名，最长 64 字符）、密码（≥ 8 位）、可选昵称。
3. 若管理员开启 **Turnstile**，完成人机验证。
4. 若开启 **邮箱验证**，查收邮件激活后再登录；否则自动登录。
5. 邮箱可能受**白名单**限制；未开放注册时页面会提示。

### 登录

1. 顶栏 **登录** → `/login`。
2. 输入注册邮箱与密码。
3. 进入 `?next=` 或默认页；**管理员**同样留在前台，通过顶栏用户菜单的「管理中心」进入 `/admin`。
4. 登录成功后，本机观看进度会**自动合并**到云端（若有）。

### 忘记密码

1. `/forgot-password` 输入注册邮箱。
2. 如果该邮箱已注册，会收到重置邮件（页面不区分账号是否存在）。
3. 打开链接到 `/reset-password` 设置新密码。

## 3. 播放

### 3.1 里番（`/watch/{id}`）

1. 打开作品后自动或手动开始播放。
2. **ArtPlayer** 播放托管 progressive MP4。
3. **右键菜单**：是否允许由管理员配置（关闭时浏览器右键也会被拦截）。
4. **广告**（若管理员启用）：
   - **片头广告**：视频优先，其次自定义 HTML，再次图片；可有倒计时与“可关闭”时间。
   - **暂停广告**：暂停正片后覆盖视频/HTML/图片；关闭后可继续播放。片头广告播放期间不会弹暂停广告；拖动进度条时一般不会误弹。

### 3.2 设备与浏览器

- 桌面与移动浏览器响应式布局。
- 建议较新的 Chrome / Edge / Safari / Firefox。
- 原生 Android 客户端为独立 UI。未登录时收藏和历史存在本机；登录后里番/漫画收藏、观看标记、漫画章节与页码通过同一账号接口与网页同步。
- Android 安装包由管理员在后台配置后，出现在页脚「浏览」栏。

## 4. 观看进度与继续观看

1. 播放时自动记录进度（起播、约每 20 秒、暂停/离开/结束）。
2. 进度 ≥ 90%（或剩余 ≤ 5 秒）记为**已看完**。
3. 首页 **继续观看**：未看完且进度超过约 5 秒的作品。
4. `/history` 可查看全部历史、清除单条或全部（清除全部会二次确认）。
5. **未登录**：进度存在浏览器 localStorage；**登录后**自动合并到账号。
6. 换设备登录同一账号可从云端进度续看。

---

## 5. 收藏

1. 里番播放页和漫画详情页用 **♡ / ♥** 开关收藏。实心为已收藏，再点取消。
2. `/favorites` 分「里番」「漫画」两块展示；卡片右上角爱心也可直接取消。
3. 不再提供想看 / 在看 / 已看完 / 自定义列表或备注。
4. 未登录点收藏会跳转登录。
5. 里番收藏走账号系统片单；漫画收藏走 `manga_favorites`。登录后网页与 App 共用同一份收藏和历史。

---

## 6. 搜索

1. 顶栏搜索会同时找里番和漫画，回车进入 `/search?q=...`。
2. 里番按片名 / 日文 / 英文 / 简介匹配；漫画按标题、作者和**漫画自己的标签**匹配。
3. 里番标签与漫画标签互不相通：播放页标签进入 `/browse?tag=`，漫画详情标签进入 `/manga?tag=`。
4. 本机保存**最近搜索**，可点击重搜或清除。
5. 里番浏览页排序：**最近更新** / **热门**。漫画目录另有日榜、周榜、月榜、总榜。

## 7. 常见问题

| 问题 | 说明 |
|------|------|
| 没有「继续观看」 | 未播放超过约 5 秒，或已标记看完 |
| 片库为空 | 管理员尚未新建或导入内容 |
| 播放失败 | 检查网络；托管地址可能失效，联系管理员 |
| 注册失败 | 未开放注册、邮箱不在白名单、或人机验证失败 |
| 收不到验证/重置邮件 | 请检查垃圾箱；若仍没有，联系站点管理员 |
