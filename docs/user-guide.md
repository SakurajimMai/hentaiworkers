# Web 前台使用指南

浏览、搜索、播放和漫画阅读无需登录。登录后可以保存收藏、同步里番播放进度，并在统一历史中
查看里番观看和漫画阅读记录。

第一次使用可先完成 [Web 首次使用教程](./tutorials/web-getting-started.md)。本页是完整行为参考；
Android 安装与客户端行为见 [移动端文档](./mobile.md)，其他资料见 [文档索引](./README.md)。

## 1. 导航与页面

桌面顶栏直接显示 **首页、里番、漫画、历史、收藏**。移动端点右上角菜单按钮后可看到同一组
入口；登录、注册或账号菜单也位于该抽屉中。日间/夜间主题按钮会把选择保存在当前浏览器。

登录后的账号菜单包含 **用户中心、我的收藏、观看历史、退出登录**；管理员另外可以进入
**管理中心**。漫画阅读页会隐藏普通顶栏，改用阅读器工具栏。

| 页面 | 路径 | 主要用途 |
|---|---|---|
| 首页 | `/` | 幻灯片、继续观看、推荐、热门、最近更新和漫画更新 |
| 里番目录 | `/browse` | 搜索或标签结果、最近更新/热门排序、分页 |
| 漫画目录 | `/manga` | 搜索、漫画标签、最近更新及日/周/月/总榜、分页 |
| 统一搜索 | `/search?q=关键词` | 同时预览里番和漫画结果 |
| 播放 | `/watch/{id}` | ArtPlayer 播放、收藏、详情和相关推荐 |
| 漫画详情 | `/manga/{slug}` | 作品信息、漫画标签、收藏和开始阅读 |
| 漫画阅读 | `/manga/{slug}/read/{n}` | 纵向连续阅读当前章节 |
| 收藏 | `/favorites` | 分别管理里番和漫画收藏，需要登录 |
| 历史 | `/history` | 游客本机观看历史，或登录后的统一云端历史 |
| 用户中心 | `/account` | 账号资料、收藏统计、修改密码和退出登录 |
| 登录/注册 | `/login`、`/register` | 使用邮箱登录或创建账号 |
| 找回密码 | `/forgot-password` | 申请密码重置邮件 |

页脚固定提供目录、历史、账号、隐私说明和使用条款。只有管理员配置了 Android 下载地址或
Telegram 后，对应入口才会出现。

## 2. 找内容：目录、搜索与标签

### 首页与目录

- 首页按站点数据显示热门、最近更新、漫画更新等栏目。登录后还可能显示根据收藏和历史生成的
  推荐；**继续观看**只列出播放超过约 5 秒且尚未看完的里番。
- `/browse` 每页显示最多 40 部里番，可在 **最近更新** 与 **热门** 之间切换。搜索、标签和
  排序条件会随分页保留。
- `/manga` 每页显示最多 30 部漫画，可切换 **最近更新、日榜、周榜、月榜、总榜**。站点
  管理员可以关闭整个漫画栏目；此时页面会明确显示“漫画暂未开放”。

### 统一搜索

1. 在顶栏输入关键词并回车，进入 `/search?q=...`。
2. 页面分别预览最多 12 条里番和 12 条漫画结果。某一类搜索失败时，另一类仍可能正常显示。
3. 结果超过预览数量时，点 **全部里番结果** 或 **全部漫画结果**，进入对应目录继续翻页。

里番匹配主标题、日文标题、英文标题和简介；漫画匹配标题、作者和漫画自己的标签。当前浏览器
最多保存 12 条最近搜索，可点选重搜或点 **清除** 删除。

### 标签

里番与漫画使用两套互不相通的标签，也没有公共标签总览页：

- 在里番播放页点标签，进入 `/browse` 的对应结果。
- 在漫画详情页点标签，进入 `/manga` 的对应结果。

标签或搜索没有结果时，使用页面上的 **返回里番馆、查看全部漫画** 等入口清除条件。

## 3. 观看里番

1. 从首页、目录或搜索结果打开作品。
2. 播放页通过 ArtPlayer 播放作品配置的 progressive 媒体地址。页面会请求自动播放；如果浏览器
   拦截自动播放，请手动点播放按钮。
3. 页面下方可查看别名、简介、剧照、标签和相关推荐，并可点 **收藏**。
4. 管理员启用时，播放器可能显示片头广告或暂停广告；右键菜单也可能被管理员关闭。

### 播放进度

- 播放开始、约每 20 秒、暂停、离开页面和播放结束时都会尝试保存进度。
- 进度达到 90%，或距离结束不超过 5 秒时，作品会标记为 **已看完**。
- 未登录时进度保存在当前浏览器，最多保留 100 条。登录成功后，站点会尝试把这些本机记录
  合并到账号。
- 登录时进度保存在账号；在另一台设备登录同一账号后，打开同一作品可从云端秒数续播。
- 自动续播只应用于超过 5 秒、尚未达到看完阈值且总时长有效的记录。

媒体地址可能来自独立源站。播放错误可能由作品地址失效、格式不支持、源站证书、防盗链、跨域
限制或当前网络造成，不应只根据“其他网页能打开”判断媒体一定可用。

## 4. 阅读漫画

### 从目录进入阅读

1. 打开 `/manga`，使用搜索、漫画标签或榜单选择作品。
2. 详情页显示封面、作者、标签、简介、页数、更新时间、收藏和推荐。
3. 点 **开始阅读** 打开第一个可用章节。当前 Web 详情页没有章节选择、上一话或下一话入口。

### 阅读器操作

- 页面按纵向连续方式显示章节图片，并在工具栏显示 `P当前页 / P总页数`。
- 工具栏包含 **返回作品、收藏、全屏、主题**。向下滚动时工具栏会收起；页面较深处会出现
  **回到顶部** 按钮。
- 阅读器按当前位置加载附近图片。单张图片失败时会显示“本页加载失败”；章节没有图片时可
  返回作品详情。
- 当前章节和页码会保存在当前浏览器。再次用同一浏览器打开同一章节时，会回到本机保存位置。

登录后，阅读器还会把章节和页码写入账号，`/history` 会显示“读到第 N 话”。当前 Web 阅读器
不会读取账号中的页码来定位；从历史点开漫画时只会进入记录的章节，具体页仍以本机记录为准。

## 5. 账号

### 注册与登录

1. 点 **注册** 或打开 `/register`。
2. 填写邮箱、至少 8 位密码和可选昵称。邮箱与昵称最长 64 个字符。
3. 根据站点设置，可能需要完成人机验证、使用白名单邮箱或先查收验证邮件。注册关闭时页面会
   明确提示。
4. 点 **登录** 或打开 `/login`，输入注册邮箱和密码。直接打开收藏、用户中心等受保护深链时，
   登录成功后会返回原页面；普通登录默认进入收藏。

管理员登录后仍停留在前台，通过账号菜单的 **管理中心** 进入后台。登录成功后，本机里番
观看进度会尽力合并到账号。

### 找回密码与用户中心

- 在 `/forgot-password` 输入注册邮箱。页面不会透露邮箱是否已注册；收到邮件后通过其中链接
  设置新密码。链接无效或过期时，请重新申请。
- `/account` 可修改显示名、查看里番/漫画收藏总数、进入历史或退出登录。
- 修改密码需要当前密码，并再次输入新密码确认。成功后当前会话失效，需要用新密码重新登录。

## 6. 收藏与分页

收藏需要登录。未登录时点收藏会跳到登录页，并在成功后返回原作品或收藏页面。

- `/favorites` 分为 **里番** 和 **漫画** 两区，两区各自每页 20 条、独立翻页。翻动里番页码
  不会重置漫画页码，反之亦然。
- 作品页可用 **♡ / ♥** 或 **收藏 / 已收藏** 切换状态；收藏页卡片右上角也可直接取消。
- 取消末页最后一项后，页面会自动回到新的有效末页，不会停留在空白的越界页。
- 两区都为空时可直接去里番或漫画目录。加载失败时点 **重新加载**，不要把错误状态当成收藏
  已被清空。

分页使用 URL 保存当前页，因此刷新、浏览器前进/后退和复制链接后仍可回到相同位置。

## 7. 历史、继续观看与清理

`/history` 在游客和登录状态下含义不同：

| 状态 | 内容 | 分页与清理 |
|---|---|---|
| 未登录 | 当前浏览器中的里番观看记录，不含漫画云端记录 | 每页 20 条；最多保留 100 条；可清除单条或本机全部 |
| 已登录 | 按最近活动合并里番观看与漫画阅读的云端时间线 | 每页 20 条；里番可单条清除；可清除全部云端历史 |

登录历史中的里番显示观看百分比或 **已看完**，点开后可按云端秒数续播。漫画显示
“读到第 N 话”，点开后进入该章节，但不会应用账号保存的具体页码。

点 **清除全部** 前会出现确认。登录状态下确认后会同时删除账号中的里番观看和漫画阅读记录，
此操作不可撤销；当前页面没有单独清除某一条漫画历史的按钮。

首页 **继续观看** 只显示未看完且进度超过约 5 秒的里番。游客数据来自当前浏览器，登录后
来自账号。

## 8. 空结果与故障处理

| 现象 | 处理 |
|---|---|
| 搜索或标签没有结果 | 更换关键词，或使用页面上的返回/查看全部入口清除条件 |
| 漫画显示“暂未开放” | 漫画栏目已由管理员关闭；里番目录仍可独立使用 |
| 收藏或历史加载失败 | 点页面内的 **重新加载**；持续失败时稍后重试 |
| 页面一直显示加载骨架 | 刷新页面；仍无结果时检查站点是否可访问并联系管理员 |
| 某部里番播放失败 | 记录作品名和播放器完整错误；再测试其他作品以区分站点与单个媒体源问题 |
| 单张漫画图片失败 | 刷新章节；持续失败时向管理员提供作品、章节和页码 |
| 链接进入 404 | 内容可能已下架或链接失效，使用页面上的 **返回首页** 或 **浏览** |
| 注册失败 | 检查注册是否开放、邮箱白名单、人机验证和密码长度 |
| 未收到验证或重置邮件 | 检查垃圾邮件；仍未收到时联系站点管理员 |

报告持续故障时，请提供页面 URL、作品名、发生时间和页面显示的完整错误。不要在普通用户设备上
执行数据库迁移或其他服务器维护命令。

## 9. Web 与 Android 的边界

本页的每 20 秒保存、看完阈值和按秒续播只描述 Web。Android 是独立客户端，其安装、更新、
本机数据和观看记录语义见 [移动端文档](./mobile.md)。跨端共享收藏和账号记录不代表两个客户端
会使用完全相同的播放或漫画定位方式。

[文档索引](./README.md) 选择 Android、管理员、部署和 API 文档。
